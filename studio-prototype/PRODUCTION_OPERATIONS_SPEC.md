# 制作记录、人效排名与运营交付规则

版本：2026-10-15。适用于星核耀火数据管理台；原型内姓名、积分、视频和网盘链接均为假设案例。

## 业务边界

| 内容 | 录入 / 修改位置 | 网页行为 |
| --- | --- | --- |
| 剧本IP立项、组织小组分配、大屏方案 | 网页 | 可操作，沿用既有功能 |
| 分镜生成归属、生成时间、制作任务、员工上传视频 | 自研制作软件 | 同步、查询、筛选，禁止网页代填 |
| 分集成片审核、员工有效时长、最终统一百度网盘链接 | 组长在制作软件完成 | 只读展示审核与回填结果 |
| 接收最终交付、平台投放信息、运营发布数据 | 网页运营页 | 可接收和回填；不在网页实际执行平台投放 |

制作软件产生业务事件，后端完成验证、存储和权限判断后同步给网页；前端显示只读提示不能代替后端鉴权。

## 制作完成与时间节点

1. 创建项目时间：使用源系统 `project.createdAt`；旧演示数据缺少该字段时显示立项时间，并标明“网页立项 / 软件项目关联”。
2. 预计项目完成时间：源系统 `plannedEnd`。仅日期时，以北京时间当日23:59:59作为截止。
3. 超时预警：未最终交付且距截止24小时内显示即将到期，超过截止显示超时天数。完成后比较实际结束时间，显示按期 / 逾期交付。当前原型即时计算预警标签，主动消息提醒由后端实现。
4. 员工生成分镜时间：每条当前生成记录保留生成员工、剧集、分镜ID、编号、时间及原始视频秒数。
5. 员工上传视频时间：制作软件保存员工、剧集、上传时间、百度网盘地址；支持多次上传。
6. 组长最终有效时长回填时间：剪辑成片经组长审核，提交每位员工的有效秒数。
7. 最终统一百度网盘链接：和最终有效时长一起提交，形成有版本号的正式交付记录。
8. **最终交付记录的 `confirmedAt` 就是项目制作结束时间**；分集全部通过、员工已上传、运营已发布，都不能替代它。
9. 运营实际投放时间与运营回填时间单独保存，不修改制作结束时间。

最终交付必须同时具备组长确认、合法百度网盘地址和有效时长结果。后续更正产生新版本，禁止覆盖旧版本的审计记录。首次完成月份按第一条有效交付确定，避免更正时重复计入首次完成数量。

## 分镜归属与有效时长

- 去重主键为项目ID + 剧集ID + 分镜ID，不能只用分镜编号跨集去重。
- 后端通过当前记录标志 `current` 给出当前成功生成归属；同一分镜重试不增加产出分镜数。存在多条当前成功记录时，原型以最新时间与ID作稳定选择，正式服务应保证唯一。
- 1—100含100个分镜，200—500含301个分镜；101—199缺少记录，不得推断为任何员工产出。
- 展示生成分镜数、原始视频秒数、审核后有效秒数三个独立字段，不互相推算。
- 员工在不同项目、剧组之间切换，不转移已经发生的积分、生成记录或审核归属。
- 原型支持按员工、编号区间筛选，40行分页。正式海量记录应由后端分页查询。
- 最终回填值替代阶段值；当分集台账与最终总值相同，保留原产出日期；有差异时，以最终回填及其产出日期为准并标识整剧更正。后端应将交付、台账修订、有效时长与消息作为同一业务事务处理。

## 人效展示

剧目详情原“集成片审核与生成归属”区域替换为员工人效横向柱状排名，不再显示分集审核列表。图表仅使用本剧累计净积分和组长确认有效分钟，按积分/有效分钟升序排列；柱长忠实表示消耗比值，越短越省。

团队页保留小组、员工排名表，删除层级树状图。无有效时长、消耗未同步、净退款为负的人员不参与排名。生成记录仍可从“有效时长”页查看，制作与运营的操作边界不变。

## 运营工作台

- 侧栏增加“运营”，有未接收最终交付时显示待办数量。
- 交付消息按交付ID与版本去重；重复同步不重复增加待办。
- 未最终交付：展示制作进度、计划、预警，禁止填写正式投放信息。
- 已最终交付：显示组长、结束时间、交付版本、最终网盘地址与提取码，运营先接收交付。
- 已接收：可填写平台、平台作品ID、实际投放时间、发布页面链接、累计浏览/播放、点赞、收藏及备注。
- 同一项目可在多个平台发布。项目 + 平台 + 平台作品ID唯一，已有记录应编辑原记录。
- 提交“确认已投放并保存”后状态为已投放；该动作记录人工已完成投放的事实，不调用平台发布接口。
- 更新发布数据替换同一作品当前累计值，不再次累加；旧快照进入历史。原有平台快照可能来自预告，不据此自动认定运营已完成正式投放。
- 交付新版本、撤回或表单版本冲突，拒绝使用旧交付提交；运营需刷新并接收最新版本。
- 真实消息由后端事件推送；当前原型为网页内待办。网页在团队和运营页每60秒读取一次最新状态，表单打开或输入期间不覆盖用户内容。

## 实现位置

- `src/domain/production.js`：完成时间、预警、分镜去重归属、区间统计、最终有效时长。
- `src/ui/production.js`：制作时间线、分集查看、生成记录筛选和员工上传记录。
- `src/ui/production.js` 的 `projectEfficiencyChart`：本剧员工人效横向柱状图。
- `src/ui/operations.js`：运营待办、进度、投放表单和发布数据。
- `src/data/mock-repository.js`：可运行的假设案例、接收和投放事务校验。
- `src/data/http-repository.js`：真实接口调用边界；原型不包含真实业务服务器。
- `API_CONTRACT.md`：接口增量、字段和服务端约束。
